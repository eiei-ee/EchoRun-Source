# Maintainers

## Primary maintainer

- [Eiei-ee](https://github.com/eiei-ee) — repository administration, releases,
  architecture, security coordination, CI, and final review.

## Responsibilities

Maintainers review issues and pull requests, protect deterministic route
safety, keep bundled assets redistributable, maintain supported builds, and
publish release notes. Changes are evaluated for player impact, portability,
test coverage, maintenance cost, and compatibility with the project license.

The project currently uses a single-maintainer model. Routine changes are
decided through public issues and pull requests. Security reports follow
[SECURITY.md](SECURITY.md). If additional contributors take sustained
responsibility for an area, this file will record their scope and role.
