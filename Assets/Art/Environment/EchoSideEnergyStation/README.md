# Echo Side Energy Station

Authored as an original low-poly trackside environment module for EchoRun.

- Source: `ArtSource/Blender/EchoSideEnergyStation.blend`
- Generator: `Tools/Art/create_echo_side_energy_station.py`
- Production model: `Models/EchoSideEnergyStation.fbx`
- Intended bounds: 4.5 m wide, 3.5 m deep, 5.5 m high
- Pivot: bottom center
- Budget: 2980 triangles, four material-batched mesh objects
- Provenance: created locally for this repository; no third-party geometry or textures

The Unity installer remaps the embedded material names to the persistent EchoRun
palette assets and creates the Resources Prefab used by `WorldStyler`.
