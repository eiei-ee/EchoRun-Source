# 影迹：层叠记忆城市

日期：2026-09-24。状态：方向已获用户认可，已接入第一段 Unity 可玩场景；此目录的图片仍是设计稿，不是实机截图。用户授权采用新的方向，不要求保留橙色。

主稿：`gameplay-keyframe-v2.png`。内置 image_gen 生成；具体提示词见 `prompts.md`。

## 方向

城市不断留下过去的奔跑痕迹。采用「灰烬台地」的错层空间组织，采用「档案迷雾」的身份记录意识，避免把整座城市做成档案柜或把玩法包装成音乐节奏游戏。

- 建筑主体是矿物蓝；石榴红墙面形成分区和视线节奏；天空和反射光偏玫瑰紫。
- 玩家识别与反制入口使用少量柠檬黄；回声为淡紫，必须有可读的独立身体轮廓，残像只作辅助。
- 色彩来自墙面、屋顶、深窗洞和材质，避免统一后期滤色把整座城市染成同一种颜色。橙色不作为主题色或身份符号。
- 宽台地、屋顶错层、室外楼梯和穿楼轨道建立城市轮廓。旧路线标记和磨损表达「留下痕迹」，不依赖墙面口号。
- HUD 直接展示谁领先、距离、剩余终点距离和伤势；预测/反制/安全仍由三道的形状及文字共同传达。不得新增契约百分比、楼层模式、预测门独立入口等并不存在的玩法。

## 界面延伸规则

- 主菜单使用同一座实际城市，玩家角色可见。开始奔跑是主操作；跑者、设置和好友挑战保留当前路由。
- 好友页聚焦收到的影子、代际和开始挑战；发布/分享为次级操作。记录感通过对齐、编号和叠边表达，不增加火漆绳结或占满画面的装饰。
- 结算先表达结果和本局表现；身份是否更新沿用真实结算状态。异步挑战不能表现成晋升或掉档。
- 字体沿用项目已验证的中文字体子集，数值预留稳定宽度。最终 UI 必须用原生文本和组件制作，不能把效果图中的文字烘焙成操作界面。
- 移动端按安全区重新布局；不能简单缩小整张横屏效果图。主操作与关键读数优先，外围纹理和装饰可减。

## 实施边界与未验证项

这张图确定材质关系、空间层次、角色识别和 UI 层级；它不是可直接导入的 3D 资产，也不是性能或碰撞验收证据。生成画面的精细建筑、植物密度、透光和远景需要在正式资源中简化并实测，不能承诺微信端逐像素复现。

首段实现复用现有平路、三道、转角及上下城市层，新增正式的退台街边建筑、楼梯和灰泥/铺石贴图，接入现有 CityV7 分块。它没有拉伸道路根节点、改变车道或增加运行时几何生成器。资源说明见 `ArtSource/Blender/LayeredMemory/README.md`，验证记录见 `docs/2026-09-24-layered-memory-slice.md`。

保护接口：车道与碰撞、相机跟随规则、AI 学习、冻结影子、单局结算及双槽存档。首段修改限于美术资源、材质/光照、主题色、回声身体材质和 HUD 布局；没有替换这些玩法实现。

效果稿已修正初稿中角色过大、装饰偏奇幻和「回声在前但写玩家领先」的问题。Windows 横屏和竖屏已有实际跑动画面；现有高架/远景仍偏方整，尚未达到效果稿的全部建筑精度。手机端性能、微信安全区及人工游玩验收仍须另行验证。
