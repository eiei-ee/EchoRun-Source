# Support

ECHO//RUN is a community-maintained public-alpha project.

- Use the bug report template for reproducible game, build, or platform issues.
- Use the feature request template for proposed improvements.
- Use [security reporting](SECURITY.md) for undisclosed vulnerabilities.
- Include the commit or release, platform, input method, reproduction steps,
  expected behavior, actual behavior, and relevant logs.

Questions about general Unity projects or commercial game production are out
of scope unless they reproduce in ECHO//RUN. There is currently no guaranteed
response time or private end-user support channel.
