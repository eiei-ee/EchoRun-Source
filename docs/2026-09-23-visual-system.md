# 影迹：整体视觉重做

这轮改真实游戏里的表层呈现。题材不限于科幻，重点是让跑道、角色、主菜单、局内信息、结算和好友挑战属于同一个游戏。取消广告式主视觉和奶油色卡片。

## 视觉规则

- 背景用墨葡萄色，信息层用深浅不同的紫色；正文是淡紫，次要内容降低明度。
- 酸黄色用于当前主要操作和玩家识别；玫红表达危险；淡紫用于回声。
- 天空、远景、近景、跑道分开明度与饱和度，避免满屏同一种紫色。
- 主菜单展示实际场景。界面优先说明当前状态、下一步操作，再提供次级信息。
- 图形和文字共同区分赛道选择；不依赖颜色识别。
- 好友界面以当前邀请和挑战为中心，发布、分享、历史邀请放在次级位置。榜单按行排列，不使用大幅宣传插画。
- 中文为主；减少大字描边、伪终端英文、无意义状态灯。

## 实现边界

共享色彩在 `EchoRunUITheme`；菜单及结算沿用 `UIManager`，局内使用正式 `EchoHud.prefab`，好友界面使用正式 `AsyncEchoSheet.prefab`。世界修改正式材质和已有运行时材质入口，不新增一套城市生成逻辑。

保留玩法状态、AI 学习算法、结算、双槽存档、异步挑战隔离、车道、碰撞体、角色骨骼及动画绑定。云部署保持暂停。本轮不升级套餐、不发布线上资源。

## 验证

备份、截图和 Windows 预览构建位于 `TestResults/VisualSystem-20260923/`。以当前真实 Unity 渲染为视觉证据，分别检查横屏、竖屏、大字、空态、错误态、弹窗焦点和游戏内操作。编译、自动测试、桌面构建与实机微信验收分别记录，不互相替代。

离线好友状态仍应可关闭并回到单机；新的视觉不得改变云调用或保存路径。

### 实施记录

- 正式 UI：主菜单展示真实场景；角色页重新分配角色预览和六个配色入口；设置、暂停、结算采用相同信息层级。主操作加重字重，其余按钮用正常字重。
- 正式 HUD：领先、剩余距离、伤势、统计和选路提示采用同一套颜色。修复 Noto CJK 行高大于旧文本框时整行消失的问题，普通及大字模式均通过字形生成回归测试。
- 好友挑战：移除宣传插画，当前邀请与开始挑战在同一区域，发布和分享可以展开；排行榜保留空态、错误态和各邀请之间的隔离。
- 场景：更新 66 个现有正式材质及城市光照，保留原纹理、模型、材质 GUID、碰撞与动画绑定；回声和玩家以淡紫及酸黄区分。
- 字体：在锁定的 Noto Sans CJK 2.004 来源上增补缺字；保留原有字符，子集共 1,053 个字符、457,256 字节，可复现构建。证据在 `TestResults/VisualSystem-20260923/font/verification.json`。
