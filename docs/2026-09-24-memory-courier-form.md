# 记忆信使形体修订

用户指出上一版仍像“方块人”。根因不只是体积：肩袖与躯干相交、胯部为独立覆盖壳，躯干、膝盖和附件的大块直角分色进一步强调了积木感。此轮改为连续、贴身的服装曲面。

## 造型与资产

- 上衣肩袖与胸背合成一个连续表面，分别定义肩线、胸腔、腰和衣摆轮廓；不再把完整袖管插进躯干。
- 裤装的腰胯、裆部与双腿合成一个连续表面，加入膝部收束与小腿弧度，移除原来的胯部覆盖壳。
- 去掉方形胸袋、裤袋、大块膝部和侧腰分色。袖口采用实际衣缘和内搭袖层，避免按减面后的三角面分色造成锯齿。
- 记忆匣改为圆弧软包形，帽顶、翻领和鞋面使用烘焙后的柔和曲面；现有柠檬黄、靛蓝与淡紫配色延续。
- 原头脸、手部、骨架、Avatar、Animator Controller、动画、角色根对象、碰撞和玩法代码未改。只在新服装表面重算肩部、胯部的骨骼权重过渡。

全部处理都在 `Tools/Blender/build_memory_courier.py` 的离线流程中完成。上衣与裤装的合并、平滑和减面不会进入运行时。生成 `.blend` 保留 38 个可编辑部件；FBX 与持久 Unity 网格仍只有一张服装网格、六种既有材质。

生成器实测主体上衣、裤装各为一个连通块，均为零非流形边。112 根原骨骼的矩阵逐一核对未变。网格边与截面相交后测量实际形体尺寸，避免减面后采样点不足导致尺寸失真。

全角色三角面增加约 19.9%，仍在原服装 11,000 面预算内。没有增加材质、贴图、光源或布料模拟。以上是资源成本，不是手机帧率结论。

证据根目录为 `TestResults/LayeredMemoryRunnerForm-20260924/`。`Baseline/` 保存本轮原件和 433 个受保护文件的哈希。`verify-form-scope.py` 只允许模型导入 meta 的自动计数，以及场景中相同材质集合的槽位顺序变化；GUID、导入选项、骨架、动作、控制、场景其余字段均保持一致。

`Before/` 为原来被指出方块感的版本，`Iteration1/` 为发现袖口分色锯齿的过程版本，`After/` 为 `08-form-install.log` 对应的最终动作采样。

现有 EditMode 检查 `09-editmode.log.xml`：26 passed、0 failed、0 skipped。覆盖人物绑定、跑步/跳跃/滑铲变形、换色、垂直动作与镜头反馈。未改测试断言，也未新增只验证建模代码自身的测试。

Windows 预览构建成功，见 `10-windows-build.log`。构建路径是 `TestResults/LayeredMemoryRunnerForm-20260924/Windows/EchoRun.exe`；独立产品名为 `EchoRun-LayeredMemory-RunnerFormReview`，与正式游戏进度分离。
