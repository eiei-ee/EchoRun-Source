# ECHO//RUN v0.1.0 — withdrawn release record

`v0.1.0` was withdrawn during asset-provenance cleanup. It is retained here
only as a historical publishing record; do not treat it as an available
download or a supported source snapshot.

First public release of ECHO//RUN, a Unity endless runner with procedural
track generation and adaptive AI gameplay systems.

## Highlights

- Procedural three-lane track generation
- Dynamic obstacle and collectible spawning
- Object pooling for runtime performance
- Persistent game progress and settings
- Adaptive AI track director and personal shadow runner
- Playable WebGL version

## Downloads

- **Windows:** Download `EchoRun-Windows-x64-v0.1.0.zip`, unzip it, then run
  `EchoRun.exe`.
- **WebGL:** Play at <https://eiei-ee.github.io/EchoRun/>.

This release does not include an Android APK. Android remains a build target,
not an official download, until a tested APK is attached to a later release.

## Integrity

Verify the Windows download against the accompanying
`EchoRun-Windows-x64-v0.1.0.sha256` file before running it.

## Known limitations

This is an early public release. Feedback and bug reports are welcome through
GitHub Issues.

The `v0.1.0` source snapshot predates the repository's asset-provenance
cleanup and may contain an unused `Assets/Fonts/arial.ttf` file with unverified
redistribution rights. Do not redistribute that source snapshot as-is; use the
current default branch or a later release. See
[THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).
