## Current-source checks

- No tracked build, cache, root test-result XML, editor credential, signing
  material, or local training export was found in the current source tree.
- Filename-only scans found no AWS access key, PEM private key, client-secret,
  API-key, access-token, or password-assignment pattern in current tracked
  source or public source-branch history.
- Existing public history exposes a `qq.com` Git author email on 170 audited
  commits. Rewriting it would change all affected commit IDs and the dependent
  deployment/PR history. The new candidate commit should use GitHub's numeric
  `users.noreply.github.com` address so it does not add another public copy of
  the personal mailbox.
- Root EditMode/PlayMode XML and `.firecrawl/` are now ignored.
- The largest current source asset is the 30.72 MiB Exo Gray FBX. Its Adobe
  Mixamo terms are disclosed in `THIRD_PARTY_NOTICES.md`.
- The bundled font, audio, Mixamo character, Unity humanoid animations, and
  WeChat Mini Game SDK now have explicit source and license records.

The local Codex checkpoint namespace contains snapshots of untracked
`Demo.zip`, `Deck.pptx`, `.firecrawl/`, and a newer FBX. Those refs exist only
inside this checkout, are not remote refs, and must never be pushed as source
or release history.

## Deployment-history findings

The `gh-pages` branch intentionally contains historical WebGL runtime files.
This explains most of the repository's reported size and includes multiple old
hash-named `.wasm`, `.data`, and framework files. Replacing the live head does
not remove those objects from deployment history.

Shrinking that history would require an explicitly approved `gh-pages` history
rewrite and force-push. It is not part of local candidate preparation and was
not performed.

## Historical exception requiring external action

Current branch heads no longer contain `Assets/Fonts/arial.ttf`. However,
GitHub still advertises:

`refs/pull/1/head -> 1f03857a2f53dd053bec8f17ad3b611d0cf761c6`

That read-only PR reference retains the pre-rewrite history containing the
0.97 MiB `Assets/Fonts/arial.ttf` blob whose redistribution rights were never
established. It also retains an old `build_android.log`; targeted inspection
found no private-key, AWS-key, secret-assignment, or WeChat-AppID pattern in
that log.

GitHub rejects ordinary attempts to delete `refs/pull/*`. Complete backend
removal therefore requires a GitHub Support request. Until that succeeds, the
repository can accurately say that current source heads are cleaned, but it
must not claim that every GitHub-retained historical ref is provenance-clean.

## Publication outcome

After maintainer approval, the reviewed source and annotated
`v0.2.0-alpha.1` tag were pushed. The exact candidate was deployed to
`https://eiei-ee.github.io/EchoRun/`; its entry page and four runtime artifacts
matched the local manifest byte-for-byte. A live browser entered the challenge,
accepted lane, jump, and slide input, and produced no console warnings or
errors. The GitHub pre-release was then published from the verified tag.

The PR-ref font exception and historical `gh-pages` size remain documented
exceptions; neither history was rewritten. No Windows or Android download is
claimed because no separately validated package was produced for this release.
