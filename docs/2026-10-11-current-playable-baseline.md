# 2026-10-11 暂定可玩基线

用户确认将当前 Windows 试玩版作为暂定基线，连同此前菜单、回声表现、HUD、
结算展示及微信安全区修订一起提交，并发布对应 WebGL。真人最终验收仍独立记录。

## 本次收口

- 首局观察、回声挑战和结算使用明确的状态事实；区分生成、提交、晋升与存储失败。
- 简化 HUD 提示与关口反馈，保留观察详情、报告入口、大字与高对比支持。
- 收敛回声材质和终点表现；微信安全区回退会重试，并定期刷新有效区域。
- 跳跃更早收腿和伸腿，落地恢复为 0.12 秒；脚踝和脚趾减少重复回勾、绷直。
  最后一轮脚部修改的实际 Humanoid 采样中，髋、膝关节旋转差为 0 度。
  跳跃脚部累计局部转角从 425.8355 降至 206.8289 度，落地从 89.5586 降至 51.2657 度。
  这些数值是各脚踝、脚趾逐帧转角的累计量，不是单次关节角度。
- 跳高 2.4 米、滞空 0.78 秒、碰撞和输入规则保持原值。

## 已有验证与边界

最新脚部版本的相关 EditMode 54/54、PlayMode 2/2 通过。连续 66 帧跳跃序列中，
跳跃和落地过渡的最小鞋底净距约 0.00716 米。独立 Windows EXE 完成 500 米
隔离存档视觉诊断，包含两次跳跃和两次滑铲；该诊断关闭障碍碰撞，不能替代正常通关。
正常窗口的主页、设置和返回按钮已经实际操作。

完整游戏改动的历史证据、旧冷白样例相机净距失败、微信和手机待验项见
[回声验收记录](2026-10-08-shadow-echo-acceptance.md)。现有 Run 循环短暂鞋底穿地
在跳跃修改前后均存在，本轮未改跑步步态。五人理解测试和手机性能未完成。
