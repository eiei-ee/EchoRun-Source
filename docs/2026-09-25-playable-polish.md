# 影迹回声：竖屏镜头与场景打磨

## 本轮目标

先做可运行的城市跑道样片，修正边道取景与首页、实战画风不一致。沿用现有城市模型和数字回声；整体科幻场景重做尚未确定。本轮未更换引擎。

## 已实现

- 镜头以跑道中心为横向基准，按实际视口宽高比保留三条车道及近身回声的空间。降低跳跃时镜头随人物起伏的幅度。
- 转弯时根据当前镜头位置对准跑道中心，消除位置与朝向独立缓动导致的玩家出框。
- 首页使用现有道路和城市资产制作的 `CityHomePreview`，进入游戏即隐藏，所有碰撞体禁用。替换原先与实战不一致的科幻插画；标题增加渐变遮罩。
- 路面使用已有 `OrangeEchoSurface` 材质着色器，去掉密集砖纹，减弱伸缩缝对比。未改动车道间距、连接点和碰撞体。
- 金币的可见模型缩至原来 72%，拾取范围、根节点和对象池不变。
- 页面配色收敛为灰蓝与青色，保留橙色主要按钮。好友挑战移除不匹配的大图及其空白占位；该页仍待微信端复核。

## 验证边界与待完成

- R2 首页发现初始骨骼位置尚未落稳导致路面偏高，已改为向实际地面射线定位；R3 实际鞋底高度检查及独立构建截图均通过。
- 动态路线诊断禁用了障碍碰撞，只用于观察场景和动作，不能代表正常碰撞验收、性能基准或人的手感验收。
- 静态取景通过不代表镜头运动舒适；为完整展示三车道，人物会比旧版小，需以手机体验判断取舍。
- 回声在拐角初段可能位于当前路面视线之外；没有宣称所有转弯时刻都能看见回声。
- 当前证据来自 Windows 本地测试包；微信包、真机帧率、资源大小与首载时间尚未重新验证。未上传云资源，未替换线上版本。

## 构建说明

当前本地试玩包：`TestResults/PortraitPolish-20260925/Windows-R3/EchoRun.exe`，同目录依赖须保留。它是开发调试构建，窗口右下角会显示 `Development Build`。本轮未改变团结引擎许可证或启动标识。

`Assets/Editor/PortraitPolishReview.cs` 可重复生成首页展示 Prefab、道路材质绑定、好友挑战 UI 及本地 Windows 样片。样片产品名 `EchoRun-Polish-Review` 用于隔离本地存档，构建后恢复项目产品名。

本机批处理宿主缺少 `ALLUSERSPROFILE`，曾使团结包管理器在编译前失败。`TestResults/PortraitPolish-20260925/RunEditor.ps1` 只在启动的编辑器进程中补回标准 Windows 公共数据目录，不修改系统环境变量。
